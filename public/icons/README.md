# App Icons

This directory should contain app icons for PWA installation.

## Required Icon Sizes:
- icon-72x72.png
- icon-96x96.png  
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Icon Requirements:
- PNG format
- Transparent background recommended
- High resolution
- Simple design that works well at small sizes

## For Development:
You can use any placeholder icons for now. For production, create icons with:
- Green farming theme
- Simple plant or leaf icon
- Works well on both light and dark backgrounds

## Tools to Create Icons:
- https://www.pwa-builder.com/image-generator
- https://realfavicongenerator.net/
- Figma or Adobe Illustrator for custom design
